# Awesome Browser

双源精选资源浏览器 —— 聚合 [sindresorhus/awesome](https://github.com/sindresorhus/awesome) 和 [0xNyk/awesome-hermes-agent](https://github.com/0xNyk/awesome-hermes-agent).

## 功能
- 😎 **Awesome 精选**: 27 分类 · 605 个全球精选开发资源列表
- 🪽 **Hermes 生态**: 12 分类 · 237 个 Hermes Agent 社区资源
- 🔍 实时搜索 / 分类导航 / 成熟度标签 / 响应式设计

## 使用
直接访问 GitHub Pages 或双击 `index.html` 离线使用。
